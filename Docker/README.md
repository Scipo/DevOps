# Docker Swarm Cluster with PHP/MySQL Application

This project automates:
1. Creation of a 3-node Docker Swarm cluster using Vagrant
2. Deployment of a PHP web application with MySQL backend

## 🛠️ Prerequisites

- [Vagrant](https://www.vagrantup.com/downloads)
- [VirtualBox](https://www.virtualbox.org/wiki/Downloads) (or other provider)
- 8GB+ RAM recommended
