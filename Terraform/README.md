# 🐳 Terraform Docker Application Deployment

This Terraform configuration automates the deployment of a containerized web application with database backend using Docker.

## 📌 Features

- **Infrastructure as Code**: Complete Docker environment defined in Terraform
- **Multi-container Setup**: Web (PHP+Nginx) and Database (MariaDB) services
- **Automatic Configuration**:
  - Network connectivity between containers
  - Database initialization

## 🚀 Quick Start

### Prerequisites
- [Terraform](https://developer.hashicorp.com/terraform/downloads) (v1.0+)
- [Docker](https://docs.docker.com/get-docker/) (v20.10+)
- Docker Compose (optional)
